# AI Trading Assistant — GitHub Pages

Опубликованная версия — образовательная статическая страница о крипторынке, волатильности, технических индикаторах и цифровой безопасности.

## Публикация

Workflow находится в `.github/workflows/deploy-pages.yml`; он публикует содержимое `public-site/` в GitHub Pages при каждом обновлении сайта.

Чтобы разрешить публикацию, открой **Settings → Pages → Build and deployment → Source** и выбери **GitHub Actions**. Затем открой Actions и проверь workflow **Publish Mini App to GitHub Pages**.

## Ограничения

GitHub Pages размещает статические файлы и не запускает Telegram-бота, API-сервер, фоновые задачи или базу данных. Поэтому эта версия не подключается к бирже и не выдаёт торговых сигналов. Для запуска собственного backend нужна отдельная серверная среда, а секреты следует задавать только в её защищённых настройках — не в клиентском коде.

Материал образовательный и не является финансовой рекомендацией.
